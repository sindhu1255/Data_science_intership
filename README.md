# Data_science_intership
Personal Introduction Program

Project Overview

This project is a simple Python program that asks the user for their name, age, and favorite hobby. It displays a personalized welcome message.

Features

- Takes user input using "input()".
- Uses variables to store information.
- Displays a welcome message using "print()".
- Uses f-strings to format the output.

How to Run

1. Open "personal_intro.py" in a Python environment.
2. Run the program.
3. Enter your name, age, and favorite hobby.

Files

- "personal_intro.py" – Python source code.
- "README.md" – Project documentation.
- "requirements.txt" – Required dependencies.

What I Learned

I learned how to use Python variables, "input()", "print()", and f-strings to create a personalized welcome message.
