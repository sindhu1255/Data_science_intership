# Sales Data Analysis Report

## 1. Introduction
This project focuses on analyzing sales data using Python and Pandas.

## 2. Objective
- To understand sales data.
- To clean the dataset.
- To calculate total and average sales.
- To identify the best-selling product.

## 3. Tools Used
- Python
- Pandas
- Google Colab

## 4. Data Cleaning
- Checked missing values.
- Removed duplicate records.
- Handled missing values.

## 5. Data Analysis
- Calculated Total Revenue.
- Calculated Average Sales.
- Identified Highest Sale.
- Identified Lowest Sale.
- Found Best Selling Product.

## 6. Conclusion
Sales Data Analysis was performed successfully using Python and Pandas.

The project helped in understanding data cleaning and basic data analysis.
